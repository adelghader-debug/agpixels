      What happened

      The application was still running in late July: development was last deployed on 28 July, production backups ran every four hours through 30 July, and every GitLab project was exported on 31 July. Certificate transparency logs show the servers still obtaining certificates until 30–31 July, and none of them had expired when the platform went dark, so certificate expiry did not cause the outage (Rev. 3 said it might; that was wrong). The tenancy is now suspended with its credit limit exhausted, and both directly-addressable origins are unreachable.

      Two explanations for the loss remain open: deliberate deletion by the departed freelancer, or automatic resource release after non-payment. ActionTrail distinguishes them — a deliberate wipe carries API calls signed by a RAM user, an automatic release does not. Retention is 90 days, so events around the 31 July export age out near the end of October.

      Why Oracle rather than staying put

      Oracle runs two Saudi regions — Riyadh and Jeddah — so block volume backups can replicate cross-region without leaving the Kingdom. SCCC has only me-central-1. Given this incident began as an unrecoverable data loss, that DR path is arguably worth more than the price difference.

      Record counts do not measure load, so these shapes are a starting point: Flex shapes resize with a reboot, not a rebuild. A second app node and a database standby for real HA bring the total to roughly $267/mo pre-VAT — still 85% below current spend, and the tier worth buying for a system clinicians depend on.
