What happened

Certificate Transparency records show TLS renewals stopped around late May 2026; the last certificates expired 11–18 August. The 28 May – 27 Jun billing cycle still charged the full ﷼6,508.60, so the tenancy was paying full rate for infrastructure that had already stopped maintaining itself. The account is now suspended with the credit limit exhausted, and both directly-addressable origins are unreachable.

Two explanations remain open: deliberate deletion by the departed freelancer, or automatic resource release following non-payment. ActionTrail distinguishes them — a deliberate wipe carries API calls signed by a RAM user, an automatic release does not. That log ages out at 90 days and the clock started in May.

Why Oracle rather than staying put

Oracle runs two Saudi regions — Riyadh and Jeddah — so block volume backups can replicate cross-region without leaving the Kingdom. SCCC has only me-central-1. Given this incident began as an unrecoverable data loss, that DR path is arguably worth more than the price difference.

Adding a second app node and a database standby for real HA brings the total to roughly $370/mo pre-VAT — still 79% below current spend. For a system clinicians depend on, that is the tier worth buying.

Fix during the rebuild

A greenfield build corrects things a restore would have carried forward: rename the databases so staging stops being called prod_back; split credentials per environment, since the handoff found them shared; build on PHP 8.4 to match the lockfiles rather than the stale server notes, preserving the archived composer.lock; enable backup policies on day one with cross-region replication to Jeddah; and remove the 10.0.0.5 record currently publishing internal addressing in public DNS.
